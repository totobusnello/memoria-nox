A methods paper on evaluating retrieval for an agent memory that changes while it is measured, in two parts kept apart.

Retrospective. Five ways the ruler misled us while building a Portuguese-language retrieval benchmark: gold keyed by chunk id decayed under re-ingest; results the oracle never judged were scored as misses; an LLM judge claimed verbatim quotes it had paraphrased, and a citation check built on them lowered agreement; an ideal built from the ranking measured ordering instead of retrieval; and part of the gold did not answer its own question, mostly because it pointed at the wrong file. These are findings of development, made and repaired on the same queries.

Prospective. A pre-registered test, frozen by the tag paper-a-prereg-v1.0 before it ran, on 120 new questions written by a model from passages drawn at random. Pooled minus strict nDCG@10 stayed above the registered margin. A blind human sample did not validate the LLM judge, which limits what the pooled figure can claim. The paper reports the pair of scores as sensitivity to the annotation protocol, not as an interval around a true value.

The corpus is private and is not released. The code-and-data archive carries the pre-registration, every script, both commitments, the printed outputs of the reading, and a provenance file that names the source of every number in the text.
