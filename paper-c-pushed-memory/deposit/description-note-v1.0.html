A dated data note on one deployment of an agent memory system, 2026-09-21 to 2026-10-23. The system pushed a short brief of memory items into each agent's system prompt on every turn. Three measurements asked whether the agents' replies show any trace of it.

A textual detector found no trace in any exposed pair of message and brief item, while a control built from items that entered the brief later matched, so the detector was not blind. A second measurement compared the served brief with a recency-ordered one on the same messages and found no trace in either, with a positive control that fired on injected items. A behavioural probe of the first action failed its own positive control, so its main phase was not run.

The note claims only this: in these protocols we did not detect a textual trace of the pushed brief, nor a change in the first action. It does not claim that the agents do not use memory. On the pull side, an agent given a task that required search searched on its own.

The transcripts are private and not released. The archive carries the note, its provenance file, and the audits, detectors and positive controls behind every number.
