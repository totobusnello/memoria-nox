memoria-nox v0.1.0

Hybrid memory with shadow discipline — yours by design.

Connection

Default: http://127.0.0.1:18802. For VPS access, use the Tailscale IP (e.g. http://100.x.y.z:18802). Bearer token required when accessing remote VPS. Stored locally only (chrome.storage.local). Encrypted with WebCrypto before write. Never synced.

Domain allowlist

The extension only acts on tabs whose hostname appears below. Default is empty — nothing is captured until you opt in per domain.

    NEVER add banking, e-mail or health domains. The extension reads the selected text on those pages on right-click — that's the threat model.

    Capture behaviour

    Type the keyword then space in the address bar to search nox-mem. Default nx. Changing this requires extension reload.

    Offline queue

    Chunks captured while nox-mem is unreachable are buffered locally (max 100, FIFO). They drain automatically when the API comes back.

    Pending: 0

    Privacy

    The A1 + A1.1 filter (13 US secret patterns + 12 BR PII patterns) runs locally before any chunk leaves the browser. PEM keys, AWS/GCP/Anthropic/ OpenAI tokens, JWTs, credit cards (Luhn-validated), CPF, CNPJ, PIX (email/phone/UUID), CEP, RG, CNH, Título de Eleitor are redacted at source.

    No third-party telemetry. Settings and queue stay in chrome.storage.local on this device only.
