What §15 registers. The confirmatory run (10.5281/zenodo.23949145) left one prediction untested: that better extraction prompts cannot reach the accuracy of a verbatim store (arXiv 2601.00821). §15 tests it on the same 242 LongMemEval s_cleaned instances with two arms restricted to the annotated evidence sessions, so that they differ only in representation: the raw turns (E-raw) and the units the revised criterion C2 distilled from them (E-dist(C2)), taken from the confirmatory cache with nothing re-distilled. Reader, judges and correctness rule are unchanged.

Primary, H4. D = acc(E-dist(C2)) − acc(E-raw), paired, judge 1, 95% cluster-bootstrap interval. Margin δ = 10 points. Upper bound below zero: the units lose to raw evidence. Lower bound above −δ: non-inferior. Both can hold; neither is inconclusive. If the two judges land in different rows, the weaker claim stands. Instrument check: acc(E-raw) ≥ 0.60. Power, simulated from the development discordance, is stated in §15.4.

The result is in the new version of the result record. The code archive holds the plan's scripts at the tag, including raw-arm.py. Not peer reviewed.
