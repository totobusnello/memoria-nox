# Abstract — The Pain Diary and Shadow Discipline

> arXiv submission: 2026-05-19
> Word count target: 150–250 words
> Style: NeurIPS-style structured abstract

---

Persistent memory for AI agents is treated as a retrieval problem, yet production deployments reveal a more fundamental failure mode: silent architectural degradation that no embedding model can prevent. GraphRAG, MemGPT, Mem0, and A-MEM model structure and recency but none encodes incident severity as a retrieval signal, and none enforces ranking-change validation before activation. NOX-Supermem's architecture is shaped by its own operational failures: each incident became a schema constraint, each lesson a feature. Three contributions follow. (1) Pain-weighted salience ($\text{salience} = \text{recency} \times \text{pain} \times \text{importance}$, $\text{pain} \in [0.1, 1.0]$) treats incident severity as a first-class retrieval dimension, calibrated against PagerDuty P1-P5 and SRE error budgets — not psychometric claims (§4.3, §5.5). Ablation ($n=31$, hybrid mode) shows directional but non-significant aggregate effect ($\Delta = +0.0065$, 95% CI $[-0.014, +0.034]$); meaningful lift appears in narrow tied-semantic regimes (Q55, $\Delta = +0.349$). The binding constraint is BM25 recall ceiling: 55 of 60 golden queries fail FTS-only retrieval regardless of pain calibration; the full hybrid pipeline retains Recall@10 = 0.6800 via the Gemini semantic layer. The transferable contribution is treating incident severity as a typed schema input; pain should be explored as a post-RRF re-ranker rather than a pre-fusion multiplier. (2) Shadow discipline enforces a minimum seven-day gate before any ranking change activates, via cron and \texttt{/api/health} as an architectural constraint, not a convention \cite{kohavi2020trustworthy,chapelle2012interleaved}. (3) Shared-canonical multi-agent context serves six agents from a single corpus without federation or merge overhead. On a 61,257-chunk corpus, hybrid retrieval (FTS5 + Gemini 3072d + RRF, $k=60$) achieves nDCG@10 = $0.5213 \pm 0.0004$ (n=50, 3-run mean) versus 0.0123 for FTS5 vanilla and 0.1475 for BM25 Pyserini (n=60) — a $3.5\times$ lift over the strongest lexical baseline. Edge-type enum coverage improved 14\%→56\% (4× gain, n=100, 95% Wilson CI [46--66\%]) via defensive prompt engineering; this is a self-reported enum coverage rate, not human-validated accuracy. On the LOCOMO conversational memory benchmark (Maharana et al., 2024, n=100 stratified subset), FTS5 alone achieves nDCG@10 = 0.281, confirming that lexical difficulty is corpus-dependent and validating the hybrid stack's calibration to identifier-dense regimes; BEIR TREC-COVID evaluation is ongoing. Full comparative positioning across seven dimensions — including corpus scale $>$100K as the remaining open gap — is in §2.5. Code, evaluation harness, golden query set (n=60), and 4-month incident log are at \url{https://github.com/totobusnello/memoria-nox} (MIT). Operational discipline is at least as important as embedding sophistication.
