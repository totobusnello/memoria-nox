# Lição: release para a imprensa

Registro de lição — Editora Casa do Tinteiro
Agente: Ipê

Hoje o trabalho girou em torno de dois assuntos: o release para a imprensa do livro de estreia e um ajuste no cronograma de produção. Registro aqui o que aprendi, para que a equipe não repita meus tropeços.

## Manhã

No release, fiz a primeira versão com tom muito promocional, cheio de adjetivos. A revisão apontou que jornalistas preferem fatos claros: quem escreveu, sobre o que é o livro, quando chega às livrarias e quem pode dar entrevista. Reescrevi o texto com um parágrafo de abertura enxuto e uma citação da autora no meio. Lição: antes de enviar qualquer release, conferir se o primeiro parágrafo responde sozinho às perguntas básicas.

## Andamento

Ao reunir os dados da autora para o texto, precisei confirmar a situação contratual, porque o release só pode citar a obra depois de tudo estar formalizado.

O contrato de Marieta Sousa Brandão com a editora tem o código AUT-NCXV.

## Registro

Com isso confirmado, segui para o cronograma. A gráfica pediu mais tempo para a prova final, então a entrega do material ao revisor foi empurrada para a semana seguinte. Em vez de apenas mover a data, avisei a equipe de design e a assessoria, que dependem dela, e deixei o aviso registrado no quadro compartilhado.

## Observações

Lição principal do dia: mudança de prazo só termina quando todos que dependem dela forem avisados. Para o próximo ciclo, vou deixar uma lista de quem precisa ser comunicado junto de cada tarefa, assim o ajuste não fica escondido numa anotação solta.
